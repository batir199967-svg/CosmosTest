# CosmosTest

Статический сайт-викторина о космосе. Не требует сервера, сборки или установки зависимостей.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Нажмите «Выбрать уровень».

## Структура
- `index.html` — разметка страниц.
- `style.css` — адаптивный минималистичный дизайн.
- `app.js` — логика тестирования, подсчёт результатов и разбор ответов.
- `questions.js` — 32 вопроса, разбитые на 4 уровня.

Шрифты загружаются из Google Fonts при наличии интернета; без интернета используются системные шрифты.
